# 📄 Задание: Модулна система за индикатори (Indicators Plugin System)

## 1. Цел на заданието
Да се създаде гъвкава, разширяема архитектура за технически индикатори във Frontend-а (HTML/JS). Всеки индикатор трябва да бъде независим модул (Plugin), който има свои собствени настройки и се включва/изключва динамично, без да изисква промяна по основния файл `index.html`.

## 2. Архитектура и структура на файловете
Трябва да се създаде нова директория `client/indicators/`. Всеки индикатор е отделен `.js` файл.
```text
📁 client/
   ├── 📄 index.html
   ├── 📄 Dockerfile (трябва да копира цялата папка, не само index.html)
   └── 📁 indicators/
        ├── 📄 volume.js
        └── 📄 ma.js
```

## 3. Стандартен интерфейс (Plugin API)
Всеки индикатор трябва да имплементира следния JavaScript обект (чрез `window.Indicators`):
```javascript
window.Indicators = window.Indicators || {};

window.Indicators.ИмеНаИндикатора = {
    id: "уникално_id",
    name: "Име за показване",
    config: { /* настройки по подразбиране */ },
    
    // Извиква се веднъж при стартиране или при превключване на таб
    init: function(chartInstance, candleSeries, config) {
        // Създаване на серии, панели и т.н.
        // Връща обект с референции, които да се пазят в паметта
    },
    
    // Извиква се при всяка нова свещ (от WebSocket)
    update: function(seriesRefs, candle, config) {
        // Изчисляване и обновяване на данните
    },
    
    // Извиква се при смяна на настройките от UI
    onConfigChange: function(seriesRefs, newConfig) {
        // Преизчисляване на индикатора
    },
    
    // Извиква се при премахване на индикатора от графиката
    destroy: function(chartInstance, seriesRefs) {
        // Изчистване на сериите от графиката
    }
};
```

## 4. Изисквания за конкретните индикатори (MVP)

### 4.1. Volume (Обем)
- **Тип:** Хистограма (Histogram Series).
- **Позиция:** В отделен панел (отделен `priceScaleId`, например `'volume'`), който заема долните 20% от графиката.
- **Конфигурация (config):**
  - `upColor`: цвят за бичи свещи (напр. `#0ecb81`).
  - `downColor`: цвят за мечи свещи (напр. `#f6465d`).
- **Логика:** Взима `candle.volume` и го рисува. Оцветява според това дали `candle.close > candle.open`.

### 4.2. Moving Average (MA)
- **Тип:** Линия (Line Series).
- **Позиция:** Върху основната графика (припокриваща се със свещите).
- **Конфигурация (config):**
  - `period`: брой свещи за изчисление (по подразбиране: 20).
  - `color`: цвят на линията (по подразбиране: `#f0b90b`).
  - `type`: тип на средната (`SMA` - Simple, `EMA` - Exponential).
- **Логика:** Изчислява средната цена за последните `N` свещи. При `SMA` – сума / N. При `EMA` – използва формулата за експоненциална средна.

## 5. UI (Потребителски интерфейс) за управление
Трябва да се добави нов бутон в лентата с инструменти (до "+" за добавяне на двойка), който отваря падащо меню **"Indicators"**.
- В менюто се показва списък с наличните индикатори (Volume, MA).
- До всеки индикатор има чекбокс за включване/изключване.
- Ако индикаторът е включен, до него се появява малка икона за настройки (зъбно колело), която отваря малък панел за редактиране на `config` стойностите (напр. период на MA).
- Промяната на настройките трябва веднага да се отразява на графиката (real-time update).

## 6. Интеграция в `index.html`
1. **Зареждане на скриптовете:** В `<head>` или преди затварящия `<body>` таг да се добавят:
   ```html
   <script src="indicators/volume.js"></script>
   <script src="indicators/ma.js"></script>
   ```
2. **Инициализация:** При създаване на таб (във функцията `switchTab`) да се проверява кои индикатори са активни и да се вика тяхната `init()` функция.
3. **Ъпдейт:** В WebSocket `onmessage` (където се обновява `candleSeries`), да се минава през всички активни индикатори и да се вика тяхната `update()` функция.
4. **Dockerfile:** `client/Dockerfile` трябва да бъде обновен, за да копира цялата директория `client` в Nginx:
   ```dockerfile
   FROM nginx:alpine
   COPY . /usr/share/nginx/html/
   EXPOSE 80
   ```

## 7. Критерии за приемане (Acceptance Criteria)
- [ ] Volume индикаторът се показва в отделен панел под свещите и се обновява в реално време.
- [ ] MA индикаторът се показва като линия върху свещите и се обновява в реално време.
- [ ] Промяната на периода на MA (напр. от 20 на 50) веднага променя линията на графиката.
- [ ] Индикаторите могат да се включват и изключват през UI, без да се презарежда страницата.
- [ ] Всеки индикатор има собствен конфигурационен обект, който може да се променя.
- [ ] Добавянето на нов индикатор изисква само създаване на нов `.js` файл и добавяне на `<script>` таг в HTML-а, без промяна по основната логика на `index.html`.
